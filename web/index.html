    What the agent did

      How it decides, and what failed

      The statistics decide. AI does the looking, the writing and the checking. AI cannot change the numbers.

      From recording to signed report

      1. Check the recording. If too many cells cannot be read, stop. No decision.
      2. Correct for speed. Bring every visit to the same flow.
      3. Measure the normal wobble. Use the repeated runs of that visit.
      4. Decide. Inside the wobble, outside it, or no decision.
      5. Write and sign. An agent writes the words. The numbers come from code and are signed.
      6. A person signs off. Nothing is final before that.

        Where else this could work

        Built for one rare disease. The method fits any lab that measures the same sample many times, records what might disturb the measurement, and compares visits. Candidates: other blood cell shape tests, stored blood quality, imaging flow cytometry, manual cell counts. None of these has been tested yet. Each one needs its own calibration.
