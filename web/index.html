Why this disease matters: VPS13A disease (Chorea-acanthocytosis)

I built HelpChoreAI as a solo developer during the hackathon to bring quality engineering to an ultra-rare, fatal disease (see scientific references in Method).

1. An ultra-rare, fatal brain disease

VPS13A disease (chorea-acanthocytosis) affects roughly 1,000 people worldwide. Loss of the lipid-transport protein chorein (VPS13A) causes movement disorders, seizures, cognitive decline and premature death. There is no approved treatment (Peikert et al., 2023).

2. Spiky red blood cells as a biomarker

Without chorein, the red blood cell membrane and cytoskeleton deform into spiky shapes called acanthocytes (Lupo et al., 2016). Because the brain cannot be biopsied at each visit, experimental drug trials (such as Lyn kinase inhibition with dasatinib) track spiky red cells in microfluidic channels (Peikert et al., 2021; Reichel et al., 2022).

3. Why I audited the measurement first

A rare-disease study has only 3 to 5 patients. One noisy visit can make an ineffective drug look like it works, or hide a real response (Rabe et al., 2021). I applied to rank candidate drugs, but the real data showed the measurement itself had never been audited. So I audited the ruler first.

Each dot is one pair of visits that a normal reading calls a change. Pick one to see it below.

Speed changes the number

Faster cells look less spiky. It is like a scale that shows less when you step on it fast. Correcting for speed can remove a false alarm, or reveal a hidden change.

    What the agent did

      How it decides, and what failed

      The statistics decide. AI does the looking, the writing and the checking. AI cannot change the numbers.

      From recording to signed report

      1. Check the recording. If too many cells cannot be read, stop. No decision.
      2. Correct for speed. Bring every visit to the same flow.
      3. Measure the normal wobble. Use the repeated runs of that visit.
      4. Decide. Inside the wobble, outside it, or no decision.
      5. Write and sign. An agent writes the words. The numbers come from code and are signed.
      6. A person signs off. Nothing is final before that.

        Where else this could work

        Built for one rare disease. The method fits any lab that measures the same sample many times, records what might disturb the measurement, and compares visits. Candidates: other blood cell shape tests, stored blood quality, imaging flow cytometry, manual cell counts. None of these has been tested on real data yet. Each one needs its own calibration.

        Try it on your own table

        Any lab can run the same rule on its own run table. One command, no model, no key. On this dataset it repeats all 32 decisions exactly.

        uv run python tools/audit_table.py examples/reichel2022_sealed_holdout.csv --reference 0.016
