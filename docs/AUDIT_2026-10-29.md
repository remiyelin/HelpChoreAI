# Audit 2026-10-29 — Findings and Fixes

Short record of each audit finding fixed so far, with the fixing commit.
(The audit was delivered as a task brief on 29 Oct; this file is the repo-side record.)

## Fixed

1. **Patient initials in tracked files and git history** (P-01). Initials moved to the
   git-ignored `private/initials_map.json`, loaded at runtime by the ingest/probe tools;
   full history rewritten whole-word only (ordinary words untouched, counts verified
   before/after: 35 whole-word matches -> 0, 8 substring-only unchanged, 6 commits kept).
   Commits: `4dbd696` (privacy chore, as rewritten), `34f9a2a` (privacy tests).
   The pre-rewrite bundle backup stays local and is never uploaded.

2. **Static-file path traversal, POST robustness, public deploy exposure** (P-02).
   Static serving is an allowlist of four paths (everything else 404 JSON; the old code
   served files outside `web/` via `..`, including `.env`); POST bodies return 400 JSON
   on malformed/missing input instead of dropping the connection; `PUBLIC_MODE=1`
   makes the demo read-only (cache hits only, `CACHE_ONLY` on miss, write endpoints
   403, badges "CACHED DEMO"); Modal attaches the keys secret only with
   `DEPLOY_WITH_KEYS=1`. Commit: `6472161`.

3. **Polygon rasterizer sign bug; SAM IoU invalid** (P-03). The ray caster divided by
   `max(dy, 1e-9)`, losing the sign for negative-dy edges and over-filling severalfold;
   the reported SAM IoU 0.14 measured the rasterizer, not SAM. Fixed with
   `src/geometry.py` (OpenCV filled contours, supersampled; SAM masks rebuilt from
   cached row spans; IoU computed outside the cache), the PromptBox half-open
   off-by-one (`max+1`) for future calls, and a cache-only re-measurement:
   IoU mean 0.140 -> 0.820 (median 0.825, range 0.693–0.916, 66.7% >= 0.80),
   median SAM/author area ratio 0.829, 0 new API calls. Commit: the commit containing
   this file (`fix(geometry): correct contour fill; SAM IoU re-measured from cache`).
